# Ubuntu 24.04 user-lifecycle smoke test — 2026-08-24

This smoke test exercised commit `01722de` and its generated offline preview
bundle on Ubuntu 24.04.4, GNOME/X11, systemd user services, and IBus 1.5.29. It
used an existing desktop user, not a fresh VM, so it does not close the
clean-machine release gate.

No API key, microphone audio, transcript, vocabulary term, or Rime user data
was read or recorded during this test. The new standalone voice service had no
configuration and therefore remained disabled and inactive.

## Verified sequence

1. Built the clean-source Ubuntu 24.04 x86_64/Python 3.12 preview from Git,
   verified its outer checksum and exact inner `SHA256SUMS`, then performed a
   real `--no-index` install of its complete wheelhouse in a fresh venv.
2. Safely removed the earlier private pre-manifest installation with that
   revision's own uninstaller, then installed from the unpacked offline bundle.
   The managed venv installed `murmur-ime-voice` 0.1.0, `sounddevice` 0.5.6,
   `websockets` 17.0.1, `cffi` 2.1.1, and `pycparser` 3.0.
3. Verified the ownership manifest, engine unit enabled/active, voice unit
   installed but disabled/inactive, and `pip check` reported no broken
   requirements with user site-packages disabled.
4. Opened the installed GTK4 settings application under Xvfb and exited it
   cleanly without creating or reading a provider configuration.
5. Re-ran the offline installer as an ownership-manifest upgrade; the exact
   previously active `libpinyin` engine was restored after component restart.
6. Validated both generated units with `systemd-analyze --user verify`.
7. Uninstalled. Both units and the complete project-owned install root were
   removed, while `libpinyin` remained active and the existing
   `~/.config/ibus/rime` directory remained present.
8. Reinstalled from the same offline bundle and repeated manifest, venv,
   IBus-engine, settings-entry-point, and service-state
   checks. The compatibility Flatpak remained able to run alongside the idle,
   disabled standalone daemon.
9. Compared a metadata-only digest over all 119 entries below
   `~/.config/ibus/rime` before and after the complete migration lifecycle; it
   was unchanged. No Rime file contents were read.

## Still required

- Repeat install, masked configure, service start/status, real inline
  dictation, upgrade, and uninstall in a fresh graphical Ubuntu user or VM.
- Repeat on Ubuntu 26.04 and representative Wayland applications.
- Use a newly rotated pre-release provider key; never reuse a key exposed in a
  chat, issue, log, or screenshot.
